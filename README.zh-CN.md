# AI 剪贴板

把 AI 回复粘成独立条目，从正文右键菜单切换历史，点右侧的段落或表格直接改字。记录只保存在本机。Windows 版使用无边框窗口，窗口中只显示正文。拖动顶部空白处可以移动窗口，拖动任意边缘或角落可以调整大小。

Windows 版运行时，按 **Ctrl + Alt + 空格** 即可唤出。菜单里的「最小化」收进任务栏，「后台运行」隐藏到系统托盘。点击托盘图标或再次启动程序也能打开。要完全关闭，请在应用菜单或托盘右键菜单中选「退出」。首选快捷键被占用时会尝试 Ctrl + Alt + M，菜单里会显示实际可用的组合。

切换到其他应用时，窗口会保持显示。正文右键或按 Shift+F10 可打开操作菜单。

## 使用

从 [GitHub Releases](https://github.com/sunshuren/mini-md-desk/releases/latest) 下载：

- **Windows x64**：双击 `AI-Clipboard.exe`，需要 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.6.2 或更高版本。
- **其他桌面系统**：下载 `AI-Clipboard.html`，用现代浏览器打开。浏览器窗口保留其自身标题栏。

粘贴 Markdown 后会立即排版，光标已在编辑框里时也一样。点击段落或表格单元格可直接编辑排版后的文字，加粗、链接和列表在编辑时保持可见。

正文默认使用暖米黄。右键系统托盘里的羽毛图标，选择「设置」即可修改背景色（浏览器版从「正文右键 → 设置」进入），关闭后仍会保留。Windows 应用支持逐显示器 DPI 感知。

打开正文右键菜单点「粘贴新条目」或在正文编辑框以外按 Ctrl+V，将剪贴板文字添加到历史。编辑框内粘贴会插入当前段落或单元格。点「打开」也可以导入 UTF-8 文本。点击菜单中的记录标题切换条目，点「删除」可移除当前记录。

表格中按 Tab 或 Shift+Tab 切换单元格。按 Ctrl+Shift+C 或点菜单中的「复制全文」取回当前 Markdown，或按 Ctrl+S（macOS 为 Cmd+S）保存文件。关闭再打开应用会恢复条目。正式留档请导出 .md。

### 从 1.0 升级

Windows 1.1 使用独立的 WebView2 本机存储。要带入旧草稿，请在 1.0 窗口导出 .md，再用新版的「打开」导入。旧窗口已关闭时，可以重新运行 1.0。HTML 版在同一浏览器和文件位置升级时会导入已有草稿。

## 图片

复制截图后按 Ctrl+V 插入，也可以从「粘贴新条目」创建图片记录。点图片或右键图片，选「复制图片」即可把单张图作为 PNG 粘到聊天或文档中。嵌入的图片随 Markdown 文件保存。仅包含外部图片网址的内容会保留链接。

## 构建

直接打开 `index.html` 即可使用浏览器版。运行 `python build.py` 在 `dist/` 生成离线 HTML。Windows 上还会用系统 .NET Framework C# 编译器生成自解包 EXE。首次构建桌面版会从 NuGet 下载固定版本的 WebView2 SDK 并校验 SHA-256。应用启动和编辑无需联网。

## 许可

应用代码采用 MIT 许可证。Markdown 解析使用 markdown-it，第三方许可随附于 `vendor/` 并嵌入 HTML。Windows 包同时携带 WebView2 SDK 的许可文件。
